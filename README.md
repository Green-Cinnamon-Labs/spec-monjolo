# spec-monjolo

> O monjolo é a máquina da roça que trabalha sozinha, movida pela água, num ciclo que não para.

Linha de pesquisa do [Green Cinnamon Labs](https://github.com/Green-Cinnamon-Labs) sobre simulação de sistemas dinâmicos: o runtime `monjolo`, cálculo numérico e o que vier disso.

## O que sei hoje

- O `monjolo` em Rust já está muito avançado. Vai ter também uma versão em Python.
- Dá para estudar cálculo numérico e coisas do tipo a partir dele.
- Talvez a linha derive para embarcados.
- Talvez eu construa, de fato, uma pequena planta industrial.
- Ainda não sei exatamente como alocar tudo isso.

Isto muda conforme eu avanço.
